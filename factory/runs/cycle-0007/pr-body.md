## Summary
Adds `__internals.fetchRemoteConfig(settings, deps?)` to the single plugin file `backend/plugin/azdo-remote-config.ts`. It fetches the shared config file through the Azure DevOps Git Items API using PAT (settings, AZDO_PAT, AZURE_DEVOPS_EXT_PAT) or an `az` bearer-token fallback. It returns `{ok,text}` or `{ok:false,error}` with fixed value-free codes and never throws. It enforces a timeout (default 5000 ms) and a 1 MiB cap, and handles lone surrogates (contract 0.6.0, ADR-0007). No runtime dependencies.
